# Round-trip examples

Example exports that show what `compare` reports. Each file is a valid capsule from `capsules/valid/` after a (simulated) import and export. Generated by `python -m cidsconformance build`.

| Export | What happened | Expected result |
|---|---|---|
| `V01-export-good.jsonld` | Same data in a different JSON-LD layout (@graph, reordered nodes, full-IRI keys). | PASS |
| `V01-export-duplicated-indicator.jsonld` | The Indicator linked to three Outcomes came back as three Indicators (DUPLICATE_NODE). | FAIL |
| `V01-export-lost-data.jsonld` | An Outcome IRI was re-minted, a description dropped, a value rewritten and a report lost. | FAIL |
| `V04-export-hascomment-clash.jsonld` | cids:hasComment came back as sff:hasComment (PREDICATE_CHANGED). | FAIL |

Try them:

```sh
python -m cidsconformance compare capsules/valid/V01-indicator-multiple-outcomes/capsule.jsonld examples/round-trip/V01-export-good.jsonld
python -m cidsconformance compare capsules/valid/V01-indicator-multiple-outcomes/capsule.jsonld examples/round-trip/V01-export-duplicated-indicator.jsonld
python -m cidsconformance compare capsules/valid/V01-indicator-multiple-outcomes/capsule.jsonld examples/round-trip/V01-export-lost-data.jsonld
python -m cidsconformance compare capsules/valid/V04-uncommon-properties/capsule.jsonld examples/round-trip/V04-export-hascomment-clash.jsonld
```
